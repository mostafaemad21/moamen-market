# سوبر ماركت مؤمن — صفحة الـ NFC

صفحة ويب واحدة تفتح أول ما الموبايل يلمس الاستاند، وفيها كل حاجة عن المحل:
الأقسام والمنتجات، الموقع على الخريطة، طرق الدفع (إنستاباي / فودافون كاش)،
والسوشيال ميديا.

مفيش أي برمجة معقدة ومفيش build — الموقع كله ملفات ثابتة تشتغل في أي متصفح.

## ✏️ إزاي تعدّل بيانات المحل

افتح ملف **`assets/js/config.js`** بأي محرر نصوص (Notepad ++ أو VS Code) — كل بيانات
المحل متجمّعة فيه. الحاجات الحالية معمولة بالفعل:

| الحاجة | المتغير | ملاحظة |
|---|---|---|
| رقم التليفون | `phone` | `01111177487` — بيظهر في زرار «اتصل» |
| رقم الواتساب | `whatsapp` | `201111177486` — بالكود الدولي بدون + |
| العنوان | `address` + `city` | بيظهر تحت الخريطة وفي جهات الاتصال |
| مكان الخريطة | `mapQuery` | إحداثيات المكان `25.046378,32.855503` (مصنع السكر — إدفو) |
| لينك جوجل مابس | `mapUrl` | زرار «افتح في الخرائط» |
| رابط الموقع | `siteUrl` | **لسه فاضي** — بعد النشر (مهم للـ QR والمشاركة) |
| لينك إنستاباي | `payments` → أول عنصر → `url` | `https://ipn.eg/S/mo2a94/instapay/0HHmDK` |
| لينك فودافون كاش | `payments` → تاني عنصر → `url` | `https://vf.eg/vfcash?id=mt&qrId=dAqxpC` |
| السوشيال | `socials` | لما تفتح حساب: حط الرابط في `url` وخلّي `soon: false` |
| الأقسام | `categories` | تقدر تزوّد أو تشيل أي قسم |
| المواعيد | `hours` | `open: 7` و `close: 1` (لو القفل بعد منتصف الليل خلي `close` أصغر من `open`) |

> **مهم:** صفحة الدفع بتقرأ اللينكات من `config.js` بس، فمش محتاج تلمس الـ HTML.
> لو حبيت تحط رقم بدل لينك: شيل `url` وحط `value` وهيظهر زرار «نسخ» مكان «افتح».

## 📡 برمجة شريحة الـ NFC

1. نزّل تطبيق **NFC Tools** (أندرويد / آيفون) — مجاني.
2. اختار **Write** → **Add a record** → **URL / URI**.
3. اكتب بالظبط:
   ```
   https://mostafaemad21.github.io/moamen-market/
   ```
4. اختار **Write** وقرّب الموبايل من الشريحة لحد ما يظهر «Done».

**نوع الشريحة المقترح:** NTAG213 أو NTAG215 (مقاومة للماء، لاصقة).
**لصقها:** جوه بلاستيك الاستاند من ورا، على ارتفاع مناسب لظهر الموبايل
(غالبًا أعلى الاستاند من الناحية اليمين أو الشمال).

> جرّب الشريحة على أكتر من موبايل (آيفون + أندرويد) قبل الطباعة النهائية.

## 🖨️ طباعة الاستاند

التصميم مقاسه **كارت عمودي رفيع ١٠ × ٢٠ سم**، وبيطلع **وشين على ورقة A4 واحدة**:

- **الوش القدام:** أيقونة NFC + «قرّب موبايلك من الاستاند» + QR
- **الوش الوراني:** طرق الدفع + السوشيال + التليفون والعنوان والمواعيد

خطوات الطباعة:

1. افتح `stand.html` في المتصفح (أو `http://localhost:5055/stand.html`).
2. اضغط زر **🖨️ اطبع**.
3. الإعدادات: **A4 — Portrait — Scale 100% — Margins: None — Background graphics: ON**.
4. اطبع على **ورق مقوى ٣٠٠ جم**، واقطع على الخط المتقطع، وحط الكارت في حامل أكريليك.

> الـ QR بيتولد أوتوماتيك من `siteUrl`، فهو خطة بديلة لأي موبايل مش بيدعم NFC.

**مكان الشريحة:** الصقها في منتصف الكارت من ورا، على ارتفاع **٧–٩ سم** من الأرض
(ده المكان اللي بيلمس ظهر الموبايل لما حد يقرّب الجهاز).
